# SMART BMS Multi User
1. Cài Node.js LTS.
2. Mở CMD trong thư mục project.
3. Chạy `npm install`
4. Chạy `npm start`
5. Máy chủ mở `http://localhost:3000`
6. Máy khác cùng LAN mở `http://IP-MAY-CHU:3000` (xem IP bằng `ipconfig`).
Cảnh báo, xác nhận và thay đổi thiết bị được đồng bộ realtime giữa các máy. Dữ liệu hiện lưu trong RAM; tắt server sẽ mất lịch sử. Bản tiếp theo có thể dùng MySQL để lưu vĩnh viễn.
